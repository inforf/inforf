## Como penso QA

Meu trabalho parte de quatro perguntas:

1. O que o usuário está tentando fazer?
2. Onde existe risco de falha ou comportamento inesperado?
3. O que vale transformar em regressão automatizada?
4. Que evidência ajuda o time a decidir com mais segurança?
